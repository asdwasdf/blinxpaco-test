# Product Knowledge

Reusable knowledge về Paco product, tích lũy qua nhiều ticket.

## Coverage Levels

- `Unknown`: chưa có thông tin
- `Minimal`: có observation ban đầu
- `Partial`: nhiều case được test
- `Substantial`: coverage tốt với provenance
- `Reviewed`: đã được BA/PO/SME review

## Structure

- `requirements/` - Atomic requirements theo feature
- `workflows/` - Multi-page/state flows
- `feature-map.md` - Feature index và coverage
- `roles-permissions.md` - Role capabilities
- `glossary.md` - Terms và aliases
- `open-questions.md` - Knowledge gaps
- `change-log.md` - Updates với timestamp
